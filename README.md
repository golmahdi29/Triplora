# Triplora

This is a simple and responsive travel landing page built with **HTML**, **CSS**, and **vanilla JavaScript**. The page is static and non-interactive, designed as a front-end template for tourism or travel-related websites.

## ✨ Features

- Clean and modern design
- Fully responsive layout
- Built using pure HTML, CSS, and JS
- Ideal as a starter template for travel agencies, blogs, or destination promotions
